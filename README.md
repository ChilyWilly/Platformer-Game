# Platformer-Game
A simple platformer game for the Terra event.
A short platformer game made using Godot. Us the arrow keys to move and the space key to jump. Click the shift key to toggle debug mode which removes collision and allows free movement. Collect all the fruit to open the door and win! Avoid the traps like spikes saw and crusher dudes, and also don't fall into the pit. Your score can be found in the top left corner.

I made this game using Godot so that I could learn the system better.

The game can be found here: https://chilywilly.itch.io/platformer-game
Click on "start game" to play the game and reload the page to restart.
